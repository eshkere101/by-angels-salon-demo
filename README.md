# By Angels — website design concept

Independent, unofficial frontend concept for By Angels Salon & Spa in Bay Harbor Islands, Florida. This repository is a design portfolio demonstration. It is not affiliated with or operated by the salon.

Images are generated illustrations, not photographs of the salon, staff or completed work. The proposed service menu must be confirmed with the business. No real appointment is booked, no payment is processed and form entries are not stored or sent.

## Contents

- index.html: page structure
- styles.css: responsive design
- app.js: browser interactions
- site-config.js: salon content and settings
- hero.jpg, blonde.jpg, nails.jpg, interior.jpg and favicon.svg: local imagery

Open index.html locally or publish the repository root with GitHub Pages. No build step or server backend is needed.
